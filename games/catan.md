# Catan (5–6 Player Extension)

> A strategy game of resource management, expansion, and negotiation.

## Goal  
Be the first player to reach 10 victory points.

## Setup  
- Use extended board  
- Each player places:
  - 2 settlements  
  - 2 roads  
- Collect starting resources  
- Distribute player pieces  

## How to Play  

### Turn Structure  
1. Roll dice (2d6)
2. Collect resources  
3. Trade (optional)  
4. Build / Buy (optional)  

### Core Mechanics  

**Resource Production**
- Based on dice rolls  
- Cities produce double  

**Trading**
- Player trades or bank (4:1 or ports)  

**Building**
- Roads (brick + wood) expand reach  
- Settlements (brick + wood + wheat + sheep) give points  
- Cities (3 ore + 2 wheat) upgrade production  
- Development (ore + wheat + sheep) cards give advantages  

### Robber (Roll of 7)  
- Players with >7 cards discard half  
- Move robber  
- Steal one card  
- Block resource production  

### Extension Rule: Special Build Phase  
- After each turn, other players can build  
- No trading allowed  
- Use only existing resources  

## End of Game  
Game ends when a player reaches 10 points.

## Win Condition  
First to 10 points wins.

## Quick Mental Model  
Roll → Trade → Build → Expand

## Strategy  
- Expand early  
- Use special build phase efficiently  
- Control key resources
